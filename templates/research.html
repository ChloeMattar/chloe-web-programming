CSS At-Rules

CSS at-rules are special instructions that tell the browser how CSS should behave. They always begin with the @ symbol.

They are used for different purposes such as importing stylesheets, creating responsive layouts, defining animations, loading custom fonts, and checking whether a browser supports a CSS feature.

Common CSS At-Rules

@import

Used to import another CSS stylesheet into the current stylesheet. 

@import "style.css";

@media

Used to apply CSS only when certain conditions are true. It is commonly used for responsive design. 

@media (min-width: 768px) {
    .container {
        width: 80%;
    }
}

@font-face

Used to load and use a custom font. 

@font-face {
    font-family: "MyFont";
    src: url("myfont.woff2");
}

@keyframes

Used to define the different stages of a CSS animation. 

@keyframes fadeIn {
    from {
        opacity: 0;
    }

    to {
        opacity: 1;
    }
}

@supports

Used to apply CSS only if the browser supports a specific CSS feature. 

@supports (display: grid) {
    .container {
        display: grid;
    }
}

Other CSS At-Rules

  • @container

    Used to apply styles based on the size or characteristics of a container instead of the whole screen.

  • @layer

    Used to organize CSS rules into layers and control their priority in the cascade.

  • @namespace

    Used to define XML namespaces in a stylesheet.

  • @property

    Used to define custom CSS properties with specific types and default values.

  • @scope

    Used to limit CSS rules to a specific part of the document.

  • @starting-style

    Used to define the starting style of an element before a transition begins.

  • @counter-style

    Used to create custom styles for counters and list markers.

<button> vs <input type="button">

Both are used to create clickable buttons in HTML, but they are not exactly the same.

<button>

The <button> element can contain text and other HTML elements inside it, such as icons, images, or spans.

Example

<button>Click Me</button>

It can also have different types: 

<button type="button">Button</button>
<button type="submit">Submit</button>
<button type="reset">Reset</button>

Advantages

  • Can contain HTML content
  • Easier to style
  • More flexible
  • Can be used as a normal button, submit button, or reset button

<input type="button">

The <input type="button"> element creates a button using the value attribute to define its text.

Example

<input type="button" value="Click Me">

Advantages

  • Simple to use
  • Useful when only a basic text button is needed

Limitations

  • Cannot contain HTML elements inside it
  • The button text must be placed inside the value attribute
  • Less flexible than <button>

Comparison

Feature <button> <input type="button">
Button text Placed between opening and closing tags Placed inside the value attribute
HTML content inside Yes No
Flexibility More flexible Less flexible
Common use Styled or content-rich buttons Simple text buttons

Main Difference

<button> can contain HTML content between its opening and closing tags, while <input type="button"> is a self-contained element and uses the value attribute for its text.

In general, <button> is more flexible and is commonly preferred when more styling or content is needed.

<datalist> vs <select>

Both <datalist> and <select> provide a list of options, but they work differently.

<datalist>

The <datalist> element provides suggestions for an <input> element.

The user can either:

  • Choose one of the suggested options
  • Type their own value

The <input> must use the list attribute, and its value must match the id of the <datalist>.

Example

<input list="browsers" name="browser">

<datalist id="browsers">
    <option value="Chrome">
    <option value="Firefox">
    <option value="Edge">
    <option value="Safari">
</datalist>

The user can type in the input and matching suggestions will appear.

<select>

The <select> element creates a drop-down list. The user normally has to choose one of the options provided.

Example

<select name="browser">
    <option value="chrome">Chrome</option>
    <option value="firefox">Firefox</option>
    <option value="edge">Edge</option>
    <option value="safari">Safari</option>
</select>

Comparison

Feature <datalist> <select>
Used with an input Yes No
Provides suggestions Yes No
User can type a custom value Yes No
User chooses from predefined options Optional Yes

Main Difference

<datalist> provides suggestions while still allowing free input.

<select> provides a fixed list of predefined choices.

JavaScript, JScript and ECMAScript

ECMAScript is the standard that defines how the language should work, JavaScript is the most common implementation of that standard, and JScript is Microsoft's older implementation.

JavaScript

JavaScript is a programming language mainly used to make web pages interactive.

It can be used to:

  • Respond to user actions
  • Change HTML content
  • Modify CSS styles
  • Validate forms
  • Create animations
  • Communicate with servers

Example

document.getElementById("demo").innerHTML = "Hello";

JavaScript was originally created by Brendan Eich in 1995 for Netscape.

JScript

JScript was Microsoft's implementation of JavaScript.

It was introduced for Internet Explorer and was designed to be compatible with JavaScript, but it had some Microsoft-specific differences.

JScript was mainly used in:

  • Internet Explorer
  • Windows scripting
  • Older Microsoft web technologies

Today, the term JScript is mostly historical, and modern browsers use JavaScript based on ECMAScript standards.

ECMAScript

ECMAScript is the official standard that defines how JavaScript should work.

It describes things such as:

  • Syntax
  • Variables
  • Functions
  • Objects
  • Classes
  • Operators
  • Control structures

JavaScript is an implementation of the ECMAScript standard. New versions of ECMAScript introduce new JavaScript features.

ECMAScript Versions

ECMAScript 5

"use strict";

ECMAScript 6

ECMAScript 6 is also called ES6 or ECMAScript 2015. 

let name = "John";
const age = 20;

ES6 introduced many important features such as:

  • let and const
  • Arrow functions
  • Classes
  • Template literals
  • Modules

Main Differences

Technology Role
JavaScript The programming language used by web developers
JScript Microsoft's older implementation of JavaScript
ECMAScript The standard that defines the rules and features of JavaScript

In Short

  • ECMAScript = the standard
  • JavaScript = the most common implementation of the standard
  • JScript = Microsoft's older implementation
