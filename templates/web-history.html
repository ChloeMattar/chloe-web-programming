What is the World Wide Web?

The World Wide Web Opened a new way to access and connect information through linked pages (hyperlinks). Tim Berners-Lee Invented the World Wide Web while at CERN, the European Particle Physics Laboratory, in 1989. He mainly described it as a place where people can share anything, global, local, draft or even highly polished. The Web works hand in hand with the Internet by providing a system of websites and web pages that users can access through web browsers.

Milestones of the History of the World Wide Web

1989

The invention of a new idea

Scientists were looking for a way to be able to share and find resources in universities and institutes all over the world for research and knowledge purposes. This is where the idea of the Web was invented by Tim Berners-Lee in 1989, with the objective of combining computer technology, data networks and hypertext into a global information system.

CERN - Tim Berners-Lee’s Original World Wide Web Proposal

1990

The beginning of the Web

The World Wide Web started with a simple proposal written by Tim Berners-Lee in March 1989, then formalized with Belgian systems engineer Robert Cailliau as a management proposal in 1990 outlining the importance of the Web. This resulted into the creation of the first World Wide Web server at CERN, developed on the NeXT computer.

W3C - A Little History of the World Wide Web

1991

First international system

Tim Berners-Lee released his first World Wide Web software. In March 1991, it became available on CERN computers, and later the software became publicly available in August 1991. It included the ‘line-mode’ browser, Web server software, and a library for developers, allowing people to access, share, and navigate information on the Web.

W3C - A Little History of the World Wide Web

1991

Going Global

After becoming publicly available, many researchers saw the World Wide Web software as an opportunity to make the Web global and accessible over the Internet rather than only locally. On December 12, 1991, the first Web server in the United States, and the first outside Europe, was established at the Stanford Linear Accelerator Center (SLAC) in California.

W3C – A Little History of the World Wide Web

1993

Bringing the Web to the World

Mosaic was an early graphical web browser released in 1993. It helped make the World Wide Web more popular by allowing users to access and share information through more visual and user-friendly web pages.

NCSA - History of Mosaic

1993

Free Web

What made the Web accessible to everyone was making the source code royalty-free, meaning that the software was finally free to use on April 30, 1993. This event made the World Wide Web increase in popularity and allowed its expansion worldwide.

W3C - A Little History of the World Wide Web

1994

Year of the Web

1994 marked a major period of growth for the Web. The first International World Wide Web Conference was held at CERN in May 1994. By the end of that year, CERN reports that the Web had around 10,000 servers and 10 million users that could’ve been creating and/or interacting with web pages.

W3C – A Little History of the World Wide Web

1994

World Wide Web Consortium

The use of the Web was growing rapidly, and its development needed to be coordinated. This resulted in the founding of the World Wide Web Consortium in October 1994 by Tim Berners-Lee at MIT, in collaboration with CERN and with support from DARPA and the European Commission. W3C helped to coordinate and create common Web standards, helping websites and browsers work consistently together.

W3C – History of the World Wide Web Consortium

1996

Introduction of CSS

Since the development of the web, it was becoming increasingly hard to format the look of the website, there was a need for a more efficient way to control its style without having to add all the visual presentation right into the HTML code. CSS Level 1 was published as a W3C Recommendation on December 17, 1996 by the World Wide Web Consortium.

W3C - CSS1 Recommendation

2014

HTML5 Adoption into Web Standards

With the evolution of the Web from a site-based technology to a platform for application development, video, audio, and interactions, there was a need for the HTML technology to grow too. This happened on October 28, 2014, when HTML5 was added by W3C as a Recommendation. HTML5 provided many capabilities required for the Web sites and applications.

W3C - HTML5 Recommendation

2019

WebAssembly: A Web Standard

As web applications gained more capabilities and started to do things that were only possible using the traditional desktop application, WebAssembly was officially recognized as a Web standard by W3C on December 5, 2019. WebAssembly is a small and efficient binary code that can be executed in web browsers, and it enables developers to build fast Web applications while leveraging other Web technologies like JavaScript.

W3C - WebAssembly Recommendation

2022

HTTP/3 Release

The Internet further developed in the direction of speed and reliability of communication, particularly for mobile changing network connections. The HTTP/3 standard was released by the IETF in June 2022 as RFC 9114. HTTP/3 uses QUIC transport protocol and offers capabilities like multiple independent streams and fast connection setup, among others.

Key Technologies

HTML

Structures the content of web pages

Hypertext Markup Language created by Tim Berners-Lee was used to create and structure content of the web using element like text, images, links, tables, etc. The HTML nowadays has many functions involving:

  1. structure content like headings, paragraphs, lists, tables.
  2. Embed media like images, audio, video.
  3. Create hyperlinks: navigate across the web.
  4. Create forms: text fields, checkboxes, buttons.
  5. Specify metadata: title, character set, viewport.

HTTP

Transfers data between web browsers and servers

Hypertext Transfer Protocol (HTTP) is a stateless, application-level request/response protocol used for communication between clients and web servers. The client sends an HTTP request to a server, and the server sends back an HTTP response containing the requested resource or information.

URI/URL

Identifies and locates resources on the web

A URI (Uniform Resource Identifier) identifies a resource on the Web. A URL (Uniform Resource Locator) is a type of URI that provides the address of a resource and indicates how it can be accessed.

URL Anatomy:

https://www.example.com/products/shoes?id=25#details

https protocol used to access the resource
www.example.com domain name
/products/shoes path to the resource
?id=25 query, used to send extra information (optional).
#details fragment, points to a specific part of the page (optional)
